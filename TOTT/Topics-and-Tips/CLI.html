CLI: Command Line Interface

CLI: Command Line Interface

A CLI is an AI tool that works in the terminal, inside a folder on your computer. It reads your files, writes new ones, moves things around, and checks its own work. Browser chat can only see what you paste into it. A CLI can see the folder.

The big three:

  • Claude Code (Anthropic)
  • Codex (OpenAI, the company behind ChatGPT)
  • Gemini CLI (Google, the company behind Gemini)

Two ways to use one

The terminal is the original, raw version: in a plain text window. For most of the Chinese models, the terminal is the only choice.

The desktop app (Claude Desktop, the Codex app, Google’s Antigravity) is a polished window built on the same underlying agent. You get a chat-style interface, buttons to approve or reject what it wants to do, file previews, and so on. Same AI, friendlier window. Start here if the terminal feels like a wall.

Why it beats browser chat

In a browser tab, you rebuild context every time: paste in the document, explain the project again, remind it what you decided last week. The conversation is where the work lives, and a chat from last week is hard to find, hard to share, and impossible to version.

A CLI flips that. The work lives in files you can read and write whenever you like, and the AI is a collaborator you invite into the folder.

Browser chatCLI in a folder
Produces an answerProduces durable work
Context is pasted in, then lostContext lives in your project files
Memory is controlled by the companyMemory can live in files you control
Suggests what you might doReads, writes, uses tools, and checks its work
Share a transcriptShare the files

“Workspace” already means something to game students using Unity or Unreal: a local project that persists between work sessions and collaborators. A CLI treats a folder of documents the same way.
